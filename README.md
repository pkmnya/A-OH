# A-OH

Plays "A-OH" whenever a terminal closes or goes idle.

---

- **English**: Plays "A-OH" whenever a terminal closes or goes idle.
- **简体中文**: 每当终端关闭或进入闲置状态时播放 "A-OH"。
- **繁體中文**: 每當終端機關閉或進入閒置狀態時播放 "A-OH"。
- **日本語**: ターミナルが終了したとき、またはアイドル状態になったときに「A-OH」を再生します。
- **한국어**: 터미널이 닫히거나 유휴 상태가 될 때마다 "A-OH"를 재생합니다.
- **Español**: Reproduce "A-OH" cada vez que una terminal se cierra o queda inactiva.
- **Français**: Joue « A-OH » chaque fois qu'un terminal se ferme ou devient inactif.
- **Deutsch**: Spielt „A-OH“ ab, wann immer ein Terminal geschlossen wird oder inaktiv ist.
- **Русский**: Воспроизводит «A-OH» каждый раз, когда терминал закрывается или переходит в режим ожидания.
